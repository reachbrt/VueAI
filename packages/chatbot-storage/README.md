# @aivue/chatbot-storage

Persist threads so a conversation survives a reload. Storage adapters for [@aivue/chatbot](https://www.npmjs.com/package/@aivue/chatbot).

## Features

- Keep a conversation after the page reloads
- Adapters for the storage you already use
- Built to sit beside `@aivue/chatbot`
- Nothing to render on its own: it stores the thread the chat window already shows
